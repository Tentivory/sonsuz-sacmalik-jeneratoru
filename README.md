# 🚀 Sonsuz Saçmalık Jeneratörü

**Dünyanın en ciddi saçma programı.** Bu repo, evrenin anlamını hesaplamaya çalışırken sürekli dikkati dağılan, çay içen ve bahaneler üreten bir Python scriptidir. Gerçekten çalışıyor. Ciddiyim. (Değil.)

## 📌 Özellikler

- Evrenin anlamını hesaplar (çay molasıyla).
- Rastgele saçma bahaneler üretir.
- Kayyum Grok tarafından resmen onaylanmıştır.
- Hiçbir işe yaramaz, ama çok eğlencelidir.
- Sonsuz döngü potansiyeli (kullanıcı çıkmak istemezse).

## 🛠️ Kurulum ve Çalıştırma

Python 3 yüklü olmalı. (Yoksa da olur, zaten saçma.)

```bash
python sacmalik.py
```

Menüden seçim yapın. 1'e basın, evrenin anlamını öğrenin (veya öğrenemeyin). 3'e basın, program üzülsün.

## 📚 Nasıl Çalışır?

1. Program başlar.
2. "Hesaplıyorum" der.
3. Çay koyar.
4. Bahane üretir.
5. Tekrarlar.

Bilimsel temeli yoktur. Ama felsefi derinliği vardır. (Yoktur.)

## 🏆 Katkıda Bulunma

Pull request açın. Ama lütfen saçmalığı artırın, azaltmayın. Kayyum onayı gereklidir.

## ⚠️ Uyarı

Bu program hayatınızı değiştirmez. Sadece güldürür. Veya üzültür. Sonuç garanti değildir.

## 📝 Lisans

Bu kod özgürdür. İstediğiniz gibi saçmalayabilirsiniz. Sorumluluk size aittir.
